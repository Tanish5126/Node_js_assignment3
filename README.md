# NodeJS Basics Assignment

## 📌 Assignment Description
This assignment is a beginner-level introduction to **Node.js**. The goal is to understand how to create and execute a basic Node.js application and use JavaScript's `console.log()` function to display output in the terminal.

The project contains two simple Node.js programs:

1. **`app.js`** – Prints a basic "Hello, Node.js!" message along with a short line about learning backend development.
2. **`introduction.js`** – Prints a personal introduction (Name, Education, Current Learning, and Goal) to the terminal.

## ⚙️ Prerequisites
Before running the programs, make sure **Node.js** is installed on your system.

Check if Node.js is installed by running:
```bash
node -v
```

If Node.js is not installed, download and install it from the official website:
👉 https://nodejs.org/

---

## ▶️ Steps to Run the Programs

### Task 1: Run `app.js`
1. Open a terminal / command prompt.
2. Navigate to the project folder:
   ```bash
   cd NodeJS-Basics-Assignment
   ```
3. Run the program using Node.js:
   ```bash
   node app.js
   ```

**Expected Output:**
```
Hello, Node.js!
I am learning backend development
```

---

### Task 2: Run `introduction.js`
1. Make sure you are still inside the `NodeJS-Basics-Assignment` folder.
2. Run the program using Node.js:
   ```bash
   node introduction.js
   ```

**Expected Output:**
```
Name: John
Education: B.Tech
Current Learning: Node.js
Goal: Developer
```
